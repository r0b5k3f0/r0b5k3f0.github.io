# 心動配對實驗室（r0b5k3f0 版）

一個採用 **Digital Garden 星空霓虹玻璃擬態風格**、繁體中文的互動小測驗。無需安裝套件、沒有後端與追蹤，已整合至 **r0b5k3f0 · Digital Garden**。

- 線上網址：`https://r0b5k3f0.github.io/tools/my-match-quiz/`

## 開始使用

1. 直接前往部署網址，或在本機靜態伺服器開啟 `/tools/my-match-quiz/` 即可遊玩。
2. 如需調整個人資料或聯絡連結，開啟 `config.js` 修改設定後儲存並重新整理網頁。

## 自訂設定（`config.js`）

- `name`：名字或暱稱（目前已設為 `r0b5k3f0`）。
- `bio`：配對成功後的自我介紹。
- `contactUrl`：社群個人頁網址，必須以 `https://` 開頭（目前已設為 `https://github.com/r0b5k3f0`，可隨時改為 Instagram、Discord 等連結）。
- `contactLabel`：聯絡按鈕文字。
- `siteUrl` / `siteLabel`：配對結果下方的個人網站入口連結與文字（預設導回 `/` 首頁數位花園）。
- `avatar`：預設 `assets/avatar.svg`。若想換成個人照片，可將正方形照片命名為 `me.jpg` 放進 `assets/`，並改為 `assets/me.jpg`。
- `title`、`subtitle`：首頁標題、副標題。

請保留字串兩側的引號與每行逗號。字串內若要換行使用 `\n`，若有雙引號使用 `\"`。

## 規則

- 第一題選女性 → 顯示第二題。
- 第二題的喜歡對象只要包含男性 → 推薦 `r0b5k3f0`；可複選其他選項。
- 第一題選男性／其他，或第二題不包含男性 → 友善的無配對結果。
- 沒有選項時，下一步停用。
- 結果由瀏覽器判斷，約 2.8 秒的等待只是趣味動畫，沒有假的科學匹配率。
- 再測一次會重新開始，不保留先前答案。重新整理回到首頁。

## 公開分享與預覽

這是純靜態網站，無需 npm、建置指令、資料庫或 API key。`index.html` 的 `<head>` 已配置 `r0b5k3f0.github.io` 的圖示與 Open Graph / Twitter Card 社群分享縮圖標籤。

## 隱私與安全

此版本不呼叫作答 API、不設 Cookie、不使用 localStorage，也不包含分析追蹤。答案只存在當前頁面的記憶體。網站託管商仍可能保留一般存取紀錄；點擊社群連結後適用該網站的政策。使用遠端頭像網址也會向該遠端服務請求圖片，建議使用隨附 `assets/` 資料夾中的本地圖片。

設定內容以純文字插入 DOM，不能用 `bio` 插入 HTML。外部聯絡連結限定 HTTPS 並以隔離 opener 的新分頁開啟。
